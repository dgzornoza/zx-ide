# Web Client

## Instalacion

```bash
npm install
```

## Comandos

Inicia el servidor de desarrollo de Vite con recarga en caliente para trabajar localmente en el web-client.

```bash
npm run dev
```

Servidor de desarrollo con recarga en caliente.

```bash
npm run build
```

Compila el cliente para produccion en `dist/`.

```bash
npm run build:watch
```

Compila en modo watch para actualizar `dist/` en cada cambio.

```bash
npm run preview
```

Previsualiza el build de produccion localmente.

```bash
npm run typecheck
```

Ejecuta verificacion de tipos sin emitir archivos.
